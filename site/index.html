Chrome setup

Manual install in 6 steps

This requires turning on Chrome's Developer mode.

  1. 1

    Download & unzip

    Download improve-focus.zip, then extract the ZIP to a folder.

  2. 2

    Open Chrome Extensions

    Type chrome://extensions in Chrome's address bar, press Enter, and turn Developer mode ON.

  3. 3

    Load Improve Focus

    Click Load unpacked, select the extracted improve-focus folder, then click Select Folder.

  4. 4

    Set up optional AI

    Open Improve Focus's Details page and make sure access to https://api.openai.com/* is ON. In Options, turn on Enable AI checking (optional) before adding your key. The key lasts only for the current browser session.

  5. 5

    Pin Improve Focus

    On the Details page, turn Pin to toolbar ON so Improve Focus stays easy to open.

  6. 6

    Start focusing

    Click the Improve Focus toolbar icon, enter one task, choose a session length, then click Start Session.

Getting started

Name the work. Start the clock.

01

Enter one task

Click the Improve Focus icon and describe the one thing you want to finish, such as “Write the launch email.”

02

Start a session

Choose how long you expect the task to take, then click Start Session. Keep browsing as usual.

03

Read the nudge

A “Stop & FOCUS” notification means the current tab looks unrelated to your task. It is a reminder, not a block, and appears only for the first unrelated tab in each session. A separate notification tells you when time is up.

Optional AI check

Use it with or without AI.

AI checking is off by default, so Improve Focus starts with its keyword check. To opt in, right-click the Improve Focus icon, choose Options, and turn on Enable AI checking (optional).

The key is kept only for the current browser session and can be removed with Delete key. While AI checking is enabled, your task, the active tab title, and its address are sent to OpenAI when a new tab is judged. OpenAI API usage may cost money.
