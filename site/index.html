Privacy at a glance

  • Permissions: alarms schedules the time-up alert; notifications shows focus alerts; storage keeps session settings; tabs reads the activated tab’s ID, title, and URL. Access to https://api.openai.com/* is only for optional AI checks.
  • Tab data: A tab’s title and URL are checked against your task when you activate it. The extension stores the tab ID and relevant/irrelevant result—not its title or URL.
  • On this Chrome profile: Your task, session state, counts, check status, and API key use chrome.storage.local. The key is saved as the plain-text value openAiApiKey; the code does not encrypt it.
  • Optional AI: Without a key, the keyword check runs on-device. For an AI check, your key is sent to OpenAI as authorization, and your task, the active tab title, and its URL are sent in the request. The request sets store: false. The source contains no analytics or developer backend.

AI is optional. Improve Focus works without it. AI relevance checks require your own OpenAI API key.

Chrome setup

Install in about two minutes.

Chrome calls this an “unpacked extension” because it comes directly from a folder, not the Chrome Web Store.

  1. 1

    Download & unzip

    Download improve-focus.zip, then extract the ZIP to a folder.

  2. 2

    Open Chrome Extensions

    Type chrome://extensions in Chrome's address bar, press Enter, and turn Developer mode ON.

  3. 3

    Load Improve Focus

    Click Load unpacked, select the extracted improve-focus folder, then click Select Folder.

  4. 4

    Set up optional AI

    Open Improve Focus's Details page. If you want AI relevance checks, make sure access to https://api.openai.com/* is ON and add your own OpenAI API key from Improve Focus Options. AI remains optional.

  5. 5

    Pin Improve Focus

    On the Details page, turn Pin to toolbar ON so Improve Focus stays easy to open.

  6. 6

    Start focusing

    Click the Improve Focus toolbar icon, enter one task, choose a session length, then click Start Session.

Getting started

Name the work. Start the clock.

01

Enter one task

Click the Improve Focus icon and describe the one thing you want to finish, such as “Write the launch email.”

02

Start a session

Choose how long you expect the task to take, then click Start Session. Keep browsing as usual.

03

Read the nudge

A “Stop & FOCUS” notification means the current tab looks unrelated to your task. It is a reminder, not a block, and appears only for the first unrelated tab in each session. A separate notification tells you when time is up.

Optional AI check

Use it with or without AI.

Without a key, Improve Focus uses a basic keyword check. If you want an AI relevance check, you must provide your own OpenAI API key.

To add one, right-click the Improve Focus icon, choose Options, paste your key, and save it. The task, tab title, and tab address are then sent to OpenAI when a tab is checked. OpenAI API usage may cost money.
